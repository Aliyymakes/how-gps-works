# gotchas.md

Traps that cut across areas. One line per entry, added at the end:
`- YYYY-MM-DD | source | X fails; do Y`. Date = last verified.

- 2026-11-22 | external | A web page cannot read satellite count or signal strength from the phone; the browser location API has no such fields. Compute satellites overhead from orbit data instead and label it as computed.
- 2026-11-22 | external | Antigravity has a size limit on rule files (reported as 12,000 characters, unverified). Keep AGENTS.md short and put detail in .memory/.
- 2026-11-22 | .gitattributes | `merge=union` keeps both sides' lines but can leave a duplicate or an odd order. Only add lines at the end of union files; never edit or reorder existing lines on a branch.
- 2026-11-22 | external | Pyodide downloads when the page first opens and that takes a few seconds (unverified how many). Show a loading message so the two-minute clock does not start on a blank page.
- 2026-11-22 | .github/workflows/tests.yml | The test workflow uses Python 3.12. Pyodide ships its own Python version; when the Pyodide version is chosen, match the workflow to it (unverified).
- 2026-11-22 | external | `gh` is not installed by default on a Mac; scripts and agents fail with "gh: command not found". Install it (`brew install gh`) and run `gh auth login` before anything else.
- 2026-11-23 | pytest.ini | Plain `pytest` puts tests/ on the import path, not the repo root, so `import mechanism` fails; pytest.ini sets `pythonpath = .`. Keep it, and run `python -m pytest -q` from the repo root.
- 2026-11-23 | web/theme.css | `.badge` sets `display: inline-flex`, which beats the `hidden` attribute; index.html adds `.badge[hidden] { display: none; }`. Do the same for any themed element you hide with `hidden`.
- 2026-11-23 | external | macOS (BSD) `sed -i` needs a suffix argument (`sed -i '' ...`); GNU-style `sed -i` fails.
- 2026-11-23 | mechanism/signal.py | `make_received` rejects a float `delay_chips` or `seed`. The page must pass whole numbers, and the bridge must turn JS integers into Python ints (Pyodide does this for safe integers; unverified until bridge.js exists).
- 2026-11-23 | external | gps.gov/technical/icwg/ and older IS-GPS-200 PDF links return 404. IS-GPS-200N is at https://www.gps.gov/sites/default/files/2025-07/IS-GPS-200N.pdf. Its Table 3-Ia text extracts scrambled; the "first 10 chips octal" for PRN 20-32 could not be read, so tests check PRN 1-19 only.
- 2026-11-23 | mechanism/signal.py | The "first 10 chips" octal in IS-GPS-200 is logic bits, and its first digit is ONE bit (1440 = 1 100 100 000). Compare against bits, not ±1 values.
- 2026-11-23 | tests/test_signal.py | At noise_std 50 the peak_to_next ratio sits between about 1.0 and 1.26 depending on the seed; the high-noise test relies on its fixed seed.
- 2026-11-23 | mechanism/geometry.py | Bunched satellites are rarely exactly singular in floating point, so `dop` gives a huge number (about 350 for four satellites within 10 degrees) rather than an error. Show large DOP values as they are; do not wait for an error to say "too bunched".
- 2026-11-23 | docs/facts.md | The "38 µs a day" relativity figure is 45 − 7 rounded; IS-GPS-200N's exact factory offset (−4.4647e-10) gives 38.58 µs a day (about 11.6 km). Say "about 38 µs" and "about 11 km", never exact.
- 2026-11-23 | docs/facts.md | Many sources quote −160 dBW for the received L1 C/A power; IS-GPS-200N gives −158.5 dBW minimum. The satellite count also depends on date (31 on gps.gov's 2023 page, 32 in an April 2026 Space Force slide): always say which date.
- 2026-11-23 | web/bridge.js | Opening bridge-test.html from file:// fails (module import and fetch need http). Serve the repo root: `python3 -m http.server 8000`. A missing mechanism file also shows the browser's own 404 line in the console next to the bridge warning (unverified).
- 2026-11-23 | mechanism/solver.py | solve_position starts at the Earth's centre, so 3 satellites in one plane with the centre and the receiver (for example overhead, north and south) give "cannot give one clear position" with solve_clock=False. Pick 3-satellite test sets with one satellite off that plane.
- 2026-11-23 | mechanism/mapview.py | mapview imports the private coords._local_directions; renaming it breaks mapview. A satellite without an "id" gives "id": None in distance_lines.
- 2026-11-23 | scripts/check_relativity.py | The "about 11 km a day" relativity figure is a range error. In this model it never becomes a position error when the clock is solved, because every satellite drifts the same. Do not say "your position would be 11 km off per day" on the page without a model that shows it.
- 2026-11-23 | web/step-geometry.js | A "spread" layout with every satellite between 20° and 60° elevation still gives PDOP about 28. Use one satellite near overhead (about 80°) plus three low ones (about 20°) 120° apart: PDOP 2.19. Checked by replaying the page's calls in Python.
- 2026-11-24 | docs/interface.md, mechanism/relativity.py | A satellite clock running ahead shortens measured distances, but relativity.py adds the drift as phone clock error (longer). The position result is the same; never write "the satellite clock gains, so distances get longer".
- 2026-11-24 | index.html, web/*.js | The page nowhere says the Earth is a sphere or the satellites are simulated; only README.md does. Do not write "the page says..." until it does.
- 2026-11-24 | external | macOS Homebrew Python refuses `pip3 install` (externally-managed-environment). Use the repo's venv: `python3 -m venv .venv`, then `.venv/bin/python -m pip install ...`. .venv/ is gitignored.
- 2026-11-24 | docs/ux-audit.md | A first visit downloads about 9 MB (Pyodide, its standard library, numpy) before any control works: 9.7 s to 44.8 s measured, 2.4 to 3.0 s on later visits. Anything the user must see in the first seconds cannot wait for Python.
- 2026-11-24 | external | Starting a local web server is refused in agent sessions. To test a branch in a real browser, let Playwright answer the live URL's requests from the working tree with `page.route()` (CDN requests pass through). Playwright turns the browser cache off when routes are on, so cache the CDN files yourself or every page load downloads 9 MB again.
- 2026-11-24 | external | In WebKit (Safari) plain Tab skips sliders, buttons and switches by default; Option+Tab reaches them. Keyboard tests in WebKit must press Alt+Tab. Not a page bug.
- 2026-11-24 | web/first-screen.js | Map lines are clipped to the map, so a line's point count changes between draws (0 when it is off the map). The solve "snap" resamples old and new lines to config.lineSamples points before gliding; a line that was off the map just appears and fades in.
- 2026-11-24 | tests/ui | The full UI suite takes about 3 minutes (Chromium and WebKit); run it in the background.
- 2026-11-24 | tests/ui/conftest.py | A Playwright sync route handler must not call time.sleep: it holds every request, local files too (a 3000 ms CDN delay pushed first paint to 3.1 s). Delay with page.wait_for_timeout, and call page.unroute_all(behavior="ignoreErrors") when a test ends with delayed requests in flight.
- 2026-11-24 | web/bridge.js | Measured after #64, warm cache: controls ready in 2.5 to 2.9 s (Chromium) and 2.8 s (WebKit); first paint at most 356 ms; one start-up freeze of 1.1 to 1.3 s while Pyodide starts (cannot be split without a Web Worker); longest frame gap while using the page 67 ms. Cold loads depend on the network (5.7 to 7.9 s here, 9.7 to 44.8 s in the item 1 audit).
- 2026-11-24 | index.html | theme.css's reduced-motion `*` rule does not reach ::before/::after or ::-webkit-slider-thumb (the switch knob and slider thumb still moved); index.html overrides them in its own style block.
- 2026-11-24 | index.html, web/step-*.js | Grids need `grid-template-columns: minmax(0, 1fr)`, or long content widens the page at 195 px (200 % zoom on a phone).
- 2026-11-24 | tests/ui/test_accessibility.py | getComputedStyle does not report slider-track colours, so the contrast test reads the CSS rule; skip the cross-origin fonts stylesheet when reading cssRules.
- 2026-11-24 | index.html, tests/ui/test_speed.py | WebKit reported no first-contentful-paint within 1 s under a slow CDN when the 'but / therefore' link lines were 16 px or had a max-width; at 18 px with no width cap it passes (3 of 3 runs). Cause not understood; re-run test_speed in WebKit after any change to .link-line.
- 2026-11-24 | index.html, tests/ui | `.hint` is opacity 0 until the class `is-shown` is added, so code that shows a hint must add that class; Playwright's is_visible() ignores opacity, so UI tests about being seen must check computed opacity (the section hints shipped invisible once because of this).
- 2026-11-24 | external | Agent worktrees are cut from the LOCAL main branch. After merging pull requests on GitHub, run `git fetch` and fast-forward local main (`git checkout main && git pull --ff-only`) before starting a new worktree, or the new branch misses the merged work.
