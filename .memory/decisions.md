# decisions.md

Implementation decisions. One line per entry, added at the end:
`- YYYY-MM-DD | source | text` (source = the file it affects, `user` when Icarus decided, `external` for a tool's behaviour). Date = last verified. A reversed decision is removed. Calls made without Icarus are marked `provisional`.

- 2026-11-22 | AGENTS.md, CLAUDE.md | AGENTS.md is the one instruction file for all agents; CLAUDE.md contains only `@AGENTS.md`. Reason: Codex and Antigravity read AGENTS.md, and Claude Code reads AGENTS.md directly only when no CLAUDE.md exists, so the import makes it certain.
- 2026-11-22 | .gitattributes | decisions.md, gotchas.md, commands.md and overview.md use git's `merge=union`, so lines added on two branches are both kept without a conflict. Reason: four people append to these files at once.
- 2026-11-22 | user | Goals, bugs and progress are GitHub Issues plus a Projects board, not files in .memory/. Reports are the pull request text.
- 2026-11-22 | docs/interface.md | Only plain numbers, strings, lists and dicts cross between Python and JavaScript. Reason: simple to convert in Pyodide and simple to explain. provisional
- 2026-11-23 | docs/interface.md, mechanism/coords.py | The Earth is a sphere of one radius, not the real slightly flattened shape. Reason: the conversions are a few lines anyone on the team can explain, and the simulated truth and the solver use the same model so results stay exact. The page must say this is a simplification. provisional
- 2026-11-23 | docs/interface.md | mechanism file names are fixed up front (constants, coords, scenario, solver, later signal and relativity) so the page's loader can list them once and two mechanism goals never edit the same file.
- 2026-11-23 | web/theme.css, web/theme.js | Instrument theme built new for this project from docs/ui-guide.md section 2 (no earlier files existed here). Fonts load from Google Fonts. Colours approved by Icarus 2026-11-23 as a first draft; radii, spacing and the switched-off satellite style are still open.
- 2026-11-23 | mechanism/signal.py | C/A chips map logic 0 → +1 and logic 1 → −1 (inferred from IS-GPS-200N Table 3-IV, not stated in words). Correlation score = dot(received, shifted code) / 1023, so a clean match scores 1.0. `peak_to_next` = best / second best; when the second best is 0 or below it returns 1e9 because infinity is not valid JSON. provisional
- 2026-11-23 | mechanism/geometry.py | `dop` reads only the unit directions receiver→satellite plus a clock column; bad input and a non-invertible layout return `{"error"}` instead of raising. A nearly bunched layout returns a very large DOP (hundreds), not an error, which is the honest answer. provisional
- 2026-11-23 | mechanism/constants.py | EARTH_RADIUS_M = 6,371,008.7714 m (GRS 80 mean radius R1, Moritz "Geodetic Reference System 1980" section 1, docs/facts.md row 33) and GPS_ORBIT_RADIUS_M = 26,559,700 m (nominal semi-major axis, SPS Performance Standard 2008 Table 3.2-3, docs/facts.md row 3). Reason: the issue asks for sourced values; facts.md already holds confirmed rows.
- 2026-11-23 | mechanism/coords.py | satellite_from_sky uses a local east/north/up frame at the receiver and walks along the sky direction to the orbit sphere (positive root of the quadratic). Out-of-range latitude also returns an error from latlon_to_xyz, and xyz_to_latlon(0,0,0) returns an error. provisional
- 2026-11-23 | tests/test_solver.py | Solver test satellites: one overhead plus four at 20° elevation, azimuths 90° apart, on a 26,571,000 m sphere (min pairwise angle 70°, all above the horizon). The old layout had satellites below the receiver's horizon. provisional
- 2026-11-23 | mechanism/mapview.py | distance_lines samples only the arc of each huge circle near the map square (half-angle asin(half_width·√2 / radius) × 1.05), doubling the samples up to 20,000 until at least 10 points land inside; inside = at least 10 points (a corner clip shorter than that is not drawn). Whether the circle reaches the square is decided geometrically first, so a corner-only line is refined instead of dropped (Codex finding on PR #28). provisional
- 2026-11-23 | scripts/check_relativity.py | A clock drift shared by every satellite (38 µs/day) is absorbed completely by the clock solve: position error 0.0000 m after 1 h, 6 h and 1 day; the solved clock error grows by the drift instead (1 µs → 39 µs after a day). With the clock trusted, the error grows from 444 m to 17.3 km. So in this model rung 4 can show the range error growing, not the position. provisional
- 2026-11-23 | mechanism/relativity.py | RELATIVITY_DRIFT_S_PER_DAY = 38e-6 in constants.py (docs/facts.md row 27, "about 38"). drift_over_time needs at least 4 satellites because the clock-solved solve does. Proposed interface row is in PR text, not in docs/interface.md (Icarus decides). provisional
